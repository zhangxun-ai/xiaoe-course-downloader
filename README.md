# 小鹅通课程批量下载器（MVP）

这是一个独立的 Chrome/Edge Manifest V3 扩展。它不会修改父目录中的飞书插件，也不会修改油猴或猫抓设置。

当前版本保留单节下载，并新增小鹅通专栏批量下载：一次识别完整目录、选择一次保存目录、自动解析每节媒体并按课程原标题保存。前三个实际下载任务会串行校准，通过后最多同时下载 2 个。

## 加载扩展

1. 在 Microsoft Edge 打开 `edge://extensions/`；Chrome 打开 `chrome://extensions/`。
2. 打开右侧或页面顶部的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本目录：

   `/Users/zhanghanting/工具箱/xiaoe-course-downloader`

5. 建议把“小鹅通课程下载器（MVP）”固定到浏览器工具栏。

扩展会显示“读取和更改所有网站上的数据”权限。这是因为小鹅通页面与真实媒体经常位于不同的 CDN 域名；扩展需要观察媒体请求并从该 CDN 流式读取文件。所有识别和下载均在本机完成，不上传媒体或课程信息。

## 批量下载

1. 登录小鹅通，打开专栏中的任意一节课程。
2. 点击课程页的“目录”，让课程目录显示出来。
3. 点击工具栏中的“小鹅通课程下载器”，再点“识别整个专栏”。
4. 在预览页核对课程总数、首节和末节。有效课程默认全部选中，也可以取消部分课程。
5. 初次使用建议先点“只测试前三节”；确认后可重新识别并点“开始全部下载”。
6. 选择一次保存目录后保持批量任务页打开。前三节串行成功后，会自动切换为最多 2 个并发。

下载文件保留原标题，例如 `65. 体制内的思考.mp3`。目标目录中的 `.xiaoe-batch-manifest.json` 用于记录完成状态；再次运行时会跳过已确认完成的文件。未知的非零同名文件不会被自动覆盖。

## 单节下载

1. 登录小鹅通，打开一节你可以正常播放的音频或视频课程。
2. 点击播放，等待 3–5 秒。
3. 点击工具栏中的“小鹅通课程下载器（MVP）”。
4. 点击“识别当前课程”。
5. 确认弹窗显示的课程标题和媒体类型正确。
6. 点击“选择目录并下载”。
7. 新任务页打开后，再点击“选择目录并开始下载”，选择一个临时测试目录。
8. 等待页面显示“下载完成”。
9. 在测试目录中检查 `001-课程标题.*`：文件应非空，并能被本机播放器正常播放。

如果同名文件已经存在，扩展会生成 `001-课程标题 (2).*`，不会覆盖原文件。

## 常见提示

- **没有发现音视频**：回到课程页播放 3–5 秒，再点击识别；必要时刷新课程页后重新播放。
- **HTTP 401/403**：课程登录可能过期，或者媒体服务器要求 Referer/Authorization。重新登录并刷新后再试；若仍失败，需要根据该课程的真实请求补充适配。
- **不支持 DRM、BYTERANGE 或直播播放列表**：扩展会明确停止，避免生成损坏文件。已支持 AES-128 点播 HLS；若密钥请求受课程权限限制，仍会提示登录或访问错误。
- **无法选择目录**：请使用最新版 Microsoft Edge 或 Chrome，并让下载任务页保持在前台。

## 当前限制

- 支持直链音视频，以及已结束的未加密或 AES-128 HLS VOD。
- 单个 HLS 内部分片按顺序下载；不处理独立音视频轨合并。
- 不处理 DRM，不绕过课程权限。
- 当前只针对已验证的小鹅通 PC 专栏页面；小鹅通页面结构变化后可能需要重新适配。
- 任务页关闭后可以从扩展入口恢复任务，但第一版不保证所有浏览器崩溃时的字节级断点续传。
