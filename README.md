<h1 align="center">小鹅通课程下载器</h1>

<p align="center">
  一个在本机运行的 Chrome / Edge 扩展，用于下载你已登录且有权访问的小鹅通单节课程或完整专栏。
</p>

> [!IMPORTANT]
> 本项目是非官方工具，与小鹅通官方无隶属或合作关系。请只下载你本人购买、获授权或拥有合法使用权的内容；本扩展不会绕过登录、付费或 DRM 保护。

## 功能概览

- **单节下载**：识别当前课程中的音频、视频直链或 HLS / M3U8 媒体。
- **专栏批量下载**：读取完整目录，自由选择课程，一次授权保存目录后自动处理。
- **安全校准并发**：前三个实际任务串行下载；确认成功后最多同时处理 2 节。
- **自动命名**：保留课程原标题，清理操作系统不允许出现在文件名中的字符。
- **任务恢复**：记录正式批量任务状态，页面意外关闭后可以继续未完成任务。
- **重复下载保护**：通过 `.xiaoe-batch-manifest.json` 核对已完成文件，避免误覆盖已有内容。
- **本地处理**：目录识别、任务状态和文件写入都在浏览器与本机完成，无遥测或第三方分析服务。

## 使用环境

- 桌面版 Google Chrome 或 Microsoft Edge。
- 可以正常登录并播放课程的小鹅通 PC 网页。
- 浏览器需要支持“目录选择”能力。它允许你手动授权一个保存目录，扩展只能在获得授权后向该目录写入文件。
- 下载期间需要保持课程登录有效；批量任务运行时请保持任务页打开。

移动端浏览器、Safari 和 Firefox 目前不在支持范围内。

## 安装扩展

本项目暂未发布到 Chrome Web Store 或 Edge 加载项商店，需要以“解压缩扩展”的方式安装。

### 方式一：下载 ZIP

1. 打开本仓库的 GitHub 页面：<https://github.com/zhangxun-ai/xiaoe-course-downloader>。
2. 点击 **Code → Download ZIP**，下载后解压。
3. 在 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
4. 打开页面上的 **开发者模式**。
5. 点击 **加载已解压的扩展程序**。
6. 选择刚刚解压、且内部直接包含 `manifest.json` 的项目目录。
7. 建议把本扩展固定到浏览器工具栏，之后可直接点击新图标使用。

### 方式二：使用 Git 克隆

```bash
git clone https://github.com/zhangxun-ai/xiaoe-course-downloader.git
```

克隆完成后，按照上面的第 3～7 步加载 `xiaoe-course-downloader` 目录。使用扩展本身不需要安装 Node.js，也不需要执行 `npm install` 或构建命令。

## 批量下载完整专栏

1. 登录小鹅通，打开目标专栏中的任意一节课程。
2. 点击课程页里的“目录”，确认专栏课程列表可以正常显示。
3. 点击浏览器工具栏中的扩展图标，再点击 **识别整个专栏**。
4. 在预览页核对课程总数、首节和末节；缺少可访问链接的课程会自动取消选择。
5. 初次使用建议点击 **只测试前三节**，然后选择一个保存目录。这里执行的是真实下载，不是模拟测试。
6. 测试成功后回到课程页，再次识别整个专栏并点击 **开始全部下载**。
7. 选择一次保存目录并保持批量任务页打开。前三个实际下载任务串行成功后，扩展会自动切换为最多 2 个并发任务。

“只测试前三节”产生的文件不会在清理测试任务时删除。正式下载再次遇到这些已验证文件时，会根据清单自动跳过。

### 批量任务控制

| 操作 | 作用 |
| --- | --- |
| 继续任务 | 从尚未完成的课程继续下载；浏览器可能再次询问目录权限。 |
| 停止任务 | 等当前正在写入的文件安全收尾后，不再派发新课程。 |
| 重试失败项 | 重新解析媒体地址并再次处理失败课程。 |
| 覆盖冲突项并重新下载 | 仅在你明确点击后，覆盖扩展判断为冲突的同名文件。 |
| 清理测试任务 | 删除测试任务状态与目录授权引用，不删除已经下载的课程文件。 |

如果正式任务页被关闭，请回到同一专栏，重新点击 **识别整个专栏**。当课程 ID 和目录内容仍与原任务一致时，扩展会找到未完成任务；进入任务页后点击 **继续任务** 即可。

## 下载单节课程

1. 登录小鹅通，打开一节能够正常播放的音频或视频课程。
2. 点击播放并等待 3～5 秒，让浏览器收到真实媒体请求。
3. 点击扩展图标，再点击 **识别当前课程**。
4. 核对课程标题和媒体类型，然后点击 **选择目录并下载**。
5. 在新打开的任务页点击 **选择目录并开始下载**，选择保存目录。
6. 等待页面显示“下载完成”，再用本机播放器检查文件。

单节下载不会覆盖同名文件。例如目标目录已经存在 `001-课程标题.mp3` 时，新文件会保存为 `001-课程标题 (2).mp3`。

## 文件与断点规则

批量下载会在保存目录中创建 `.xiaoe-batch-manifest.json`。这是扩展的本地完成清单，记录课程、文件名、字节数和验证状态。

- 再次运行同一专栏时，已被清单确认且大小匹配的文件会自动跳过。
- 扩展不会静默覆盖来源不明的非空同名文件，而是将该课程标记为“文件冲突”。
- 下载失败时会尽量移除本次产生的不完整文件，保留原有非空文件。
- 请不要手动编辑清单。若需要移动课程，建议连同课程文件和清单一起移动。
- 任务可以按课程级别恢复，但当前不保证浏览器崩溃后的单个文件字节级续传。

## 权限与隐私

浏览器会提示本扩展“读取和更改所有网站上的数据”。小鹅通页面与真实媒体通常位于不同的动态 CDN 域名，因此扩展需要跨域观察媒体响应并读取文件。当前权限用途如下：

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 在你点击扩展时定位当前课程标签页。 |
| `scripting` | 按需读取当前课程的标题、媒体元素和专栏目录。 |
| `storage` | 在本机保存临时识别结果、批量任务状态和恢复索引。 |
| `webRequest` | 观察媒体响应 URL 与 `Content-Type`，帮助识别动态音视频地址。 |
| `<all_urls>` | 访问实际承载课程媒体的不同 CDN 域名并下载文件。 |

扩展会在浏览器会话中临时保存各标签页识别到的媒体候选地址，标签页关闭后会清理；持久化批量任务时不会保存临时签名媒体 URL。当前源代码没有课程上传、账号收集、遥测或广告逻辑，但跨站点权限本身能力较强，请只从你信任的源码安装。

## 支持范围与已知限制

当前支持：

- 常见音视频直链：AAC、FLAC、M4A、MOV、MP3、MP4、OGG、WAV、WebM。
- 已结束的 HLS / M3U8 点播；主播放列表会选择最高带宽变体。
- 未加密 HLS，以及使用标准 AES-128 加密的点播分片。
- 小鹅通 PC 专栏页中当前已适配的目录结构。

当前不支持：

- DRM、SAMPLE-AES、非标准密钥格式或绕过课程访问权限。
- 直播播放列表、`BYTERANGE` 分片和独立音视频轨合并。
- 无法在当前账号中正常打开或播放的课程。
- 小鹅通改版后尚未适配的新页面结构。

## 常见问题

| 提示或现象 | 处理方法 |
| --- | --- |
| 没有发现音视频 | 回到课程页播放 3～5 秒后再次识别；仍无结果时刷新页面、重新播放再试。 |
| 无法读取专栏目录 | 确认当前是小鹅通 PC 专栏课程页，并先打开页面中的“目录”；刷新或重新登录后重试。 |
| HTTP 401 / 403 | 登录可能已过期，或 CDN 额外校验 Referer / Authorization。重新登录并刷新；若仍失败，说明该课程可能需要新的适配。 |
| 无法选择目录 | 使用桌面版 Chrome / Edge，确认任务页处于前台；升级浏览器后重新加载扩展。 |
| 文件冲突 | 先检查同名文件内容。可以移动或重命名原文件，也可以在确认风险后点击“覆盖冲突项并重新下载”。 |
| 不支持 DRM、BYTERANGE 或直播 | 当前版本会主动停止以避免生成损坏文件，不能通过重试解决。 |
| 任务页被关闭 | 回到同一专栏重新识别目录，找到恢复任务后点击“继续任务”。 |

## 更新与卸载

通过 ZIP 安装时，需要重新下载并解压新版文件；通过 Git 安装时，在项目目录执行：

```bash
git pull
```

更新文件后回到 `chrome://extensions/` 或 `edge://extensions/`，点击本扩展卡片上的 **重新加载**。开发者模式加载的扩展不会自动更新。

卸载扩展会清除浏览器内保存的任务状态，但不会删除你已经下载到本机目录中的课程文件。

## 开发与验证

项目使用原生 JavaScript 和 Manifest V3，没有运行时第三方依赖，也没有构建步骤。主要目录如下：

```text
icons/             扩展图标 SVG 母版与各尺寸 PNG
content-scripts/   当前课程与专栏目录识别脚本
shared/            下载、HLS、批量调度和文件状态逻辑
tests/             Node.js 自动化测试
manifest.json      Chrome / Edge 扩展入口与权限声明
```

安装较新的 Node.js 后，可在项目根目录运行完整测试：

```bash
npm test
```

测试使用 Node.js 内置测试运行器，不需要先安装 npm 依赖。
