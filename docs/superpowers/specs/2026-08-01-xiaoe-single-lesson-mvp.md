# 小鹅通单节课程下载器 MVP 设计

## 目标

在 Chrome/Edge 中加载一个独立扩展。用户登录并打开一节有权访问的小鹅通课程、播放媒体后，扩展识别当前页面的音频或视频资源；用户选择目录后，扩展把一个文件写入该目录，并按 `001-课程标题.扩展名` 命名。

## 边界

- 新扩展全部位于 `xiaoe-course-downloader/`，不修改现有飞书插件、油猴或猫抓配置。
- 只处理当前页面的一节课程；不做整栏队列、并行下载和后台自动翻页。
- 支持可直接请求的音频/视频文件，以及未加密的 HLS（M3U8）播放列表。
- 不绕过 DRM，不破解无权访问的内容；登录和课程访问由用户在浏览器中完成。
- 第一版每次下载都由用户选择目标目录，避免引入持久目录授权和恢复逻辑。

## 架构

1. MV3 后台脚本通过 `webRequest` 只观察浏览器已经发出的媒体请求，并按标签页把候选地址暂存到 `chrome.storage.session`。
2. 弹窗按用户点击执行页面扫描，收集 `<audio>`、`<video>`、`<source>` 和 Resource Timing 中的候选地址，再与后台观察结果合并并选出最佳媒体。
3. 弹窗把单节下载任务临时写入 `chrome.storage.session`，打开持久的扩展任务页；任务页读取后立刻删除该记录，避免长期保存带签名参数的媒体 URL。耗时下载不在容易关闭的弹窗内运行。
4. 任务页由用户手势调用 `showDirectoryPicker()`，通过 File System Access API 流式写入文件。
5. 直链使用带 `credentials: "include"` 的单次流式 `fetch`；HLS 解析主播放列表，选择最高带宽变体，然后按顺序写入初始化段和媒体分片。根据分片和 `EXT-X-MAP` 推断 `.ts`、`.aac` 或 `.mp4` 输出，绝不把媒体字节命名为 `.m3u8`。

小鹅通媒体可能来自独立 CDN，因此第一版声明 `<all_urls>` 主机权限。扩展不上传、转发或持久记录课程内容，只保留当前标签页最多一小组候选 URL。

## 成功和错误反馈

- 下载完成必须满足：HTTP 请求成功、写入字节数大于零、文件流正常关闭。
- 没有候选资源时，提示用户先播放课程数秒后重新识别。
- 顶层页面重新导航或标签页关闭时清理该标签页的旧候选，避免把上一节课程误选为当前课程。
- 发现加密 HLS、`EXT-X-BYTERANGE`、`EXT-X-SESSION-KEY`、直播/缺少 `EXT-X-ENDLIST`、DRM、403/过期链接或浏览器不支持目录选择时，显示具体原因，不静默产出损坏文件。
- 如果媒体服务器要求扩展请求无法安全复现的 Referer 或 Authorization，第一版明确报错并停止；实际小鹅通登录课程必须通过浏览器验收确认 `credentials: "include"` 足够。
- 文件名移除操作系统不允许的字符，并限制长度。

## 验证

- Node 单元测试覆盖媒体分类/排序、文件名清理、HLS 输出扩展名推断，以及不支持播放列表的拒绝逻辑。
- 静态检查扩展清单与所有引用文件。
- 浏览器人工验收：加载未打包扩展，在一节小鹅通课程中播放数秒，识别资源，选择临时目录，确认生成的文件名称正确、非空且可播放。
