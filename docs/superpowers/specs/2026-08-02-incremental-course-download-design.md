# 小鹅通增量下载最小设计

## 目标

选择一个已有课程文件的目录后，仅下载缺失课程；后续专栏更新时也只下载新增课程。

## 判定顺序

1. 以 `courseId + lessonId` 的下载清单作为主依据。
2. 清单有记录且对应文件存在、文件头是受支持的音视频格式时，跳过。如文件存在但无效，删除该条“已完成”记录并返回冲突，保留非空文件。
3. 清单有记录但文件已不存在时，删除该条陈旧记录，返回待下载。
4. 清单无记录时，仅扫描以“完整集数 + 明确分隔符”开头的文件，同时支持 `87. 标题.mp3` 和 `87-标题.mp3`，不允许 `8` 匹配 `87`。
5. 只有“集数精确 + 规范化标题精确 + 文件头有效”的唯一文件才纳入清单并跳过；标题不同、多个匹配或文件无效时标记冲突，不覆盖。
6. 没有匹配时才解析媒体并下载。

## 下载安全

- 空的 `<audio>` 地址不得解析成当前课程网页。
- HTTP 响应是 HTML、JSON 或其他明显非媒体内容时立即失败。
- 只有写入完成且文件头可验证时才写入“已完成”清单。
- 不自动删除用户的非空文件；不确定时停在冲突状态。
- 目录协调复用现有 `courseId + lessonId` 任务锁、文件锁和中断恢复；`createWritable()` 只在完整写入并校验后关闭落盘，不另造一套并发系统。

## 当前目录迁移

- 用户已删除 1–63 的错误 `.bin`。
- 执行时逐条清理指向不存在 `.bin` 的陈旧清单记录。
- 将目录内现有的 24 个有效 MP3 纳入清单，不改名、不重下。
- 下载 1–63 和缺失的第 67 节。

## 必要测试

- 空媒体地址不产生课程页 URL 候选。
- HTML 响应不得写入并记录为成功。
- 有效的点号/连字符旧 MP3 能被纳入清单并跳过。
- 文件缺失的陈旧清单记录会被清除并重新下载。
- 清单标记完成但现有文件无效时，清除完成记录、保留文件并返回冲突。
- 匹配不唯一时返回冲突，不覆盖文件。
